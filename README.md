# 🐍 Python Básico — Cuaderno 01

Primer cuaderno de una serie dedicada al aprendizaje de **Python** desde cero.
Este cuaderno cubre los **fundamentos del lenguaje**: variables, tipos de datos,
operadores, estructuras de control, estructuras de datos y funciones.

> ⚠️ **Nota:** Este es un cuaderno *introductorio*. Python tiene una infinidad
> de librerías y campos de aplicación.

---

## 🎯 Objetivos

Al terminar este cuaderno serás capaz de:

- Entender qué es Python y cómo ejecutarlo en Google Colab.
- Declarar variables y reconocer los tipos de datos básicos.
- Usar operadores aritméticos, lógicos y de comparación.
- Manipular cadenas de texto (strings).
- Controlar el flujo de un programa con condicionales y bucles.
- Trabajar con listas, tuplas, diccionarios y sets.
- Definir y usar tus propias funciones.
- Manejar errores básicos con `try` / `except`.
- Importar y usar módulos de la biblioteca estándar.
